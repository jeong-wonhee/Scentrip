# 디자인 QA — 원본 프로토타입 ↔ 배포본 (2026-09-16)

원본 프로토타입(`screens/*.html`)과 배포본(https://scentrip.vercel.app)의 차이를 정리한 폴더입니다.

## 읽는 순서

1. **[QA-REPORT.md](QA-REPORT.md)** — 상단 요약(심각도별·페이지별 건수, 핵심 5줄)을 먼저 보고, 그다음 티켓을 봅니다. 티켓은 P0 → P1 → P2 순서이고, 같은 심각도 안에서는 페이지 순서입니다.
2. 티켓마다 `상세: qa/0N-*.md F번호`가 있습니다. 같은 항목의 표 형태 기록과 부록(약관 조항 대조, 16유형 결과 대조, 토큰 표, 너비 매트릭스, 링크 전수 대조)은 단계별 문서에 있습니다.

| 문서 | 내용 |
|---|---|
| [00-page-map.md](00-page-map.md) | 원본 화면·상태 ↔ 배포 URL 매핑 |
| [01-text.md](01-text.md) | 문구 · 기획 대조 |
| [02-style.md](02-style.md) | 스타일(컴퓨티드 스타일 수치) · 토큰 대조 |
| [03-width.md](03-width.md) | 창 너비 1440 / 1280 / 1024 / 640 동작 대조 |
| [04-flow.md](04-flow.md) | 링크 · 버튼 이동 · 뒤로가기 대조 |

## 티켓 보는 법

- **기대(디자인)** 는 원본 값이고, 근거는 이 레포의 `파일:줄`입니다. **실제(배포)** 는 배포본에서 측정한 값과 스크린샷입니다.
- 스크린샷: `screens/{화면}-{너비}-{design|dev}.png`. 용량 때문에 256색으로 압축했습니다. **정확한 색상값은 스크린샷이 아니라 문서에 적힌 수치를 기준으로** 봐 주세요.
- 원본 카드의 샘플 데이터(장소명·"Description" 같은 자리표시자)와 실데이터의 값 차이는 대조하지 않았습니다. 라벨·문구 규칙·구성·형식·스타일·동작만 대조했습니다.

## 티켓이 아닌 목록 (QA-REPORT 하단)

- **원본에 없는데 배포본에 있는 항목** — 원본에 반영할지, 배포본에서 뺄지 기획·디자인 결정이 먼저 필요합니다.
- **원본 확인 필요** — 원본 자체에 문제가 있어 보이는 부분입니다. 개발 수정 대상이 아닙니다.
- **확인필요** — 검수하지 못한 항목입니다.

## 참고

- SCT 번호는 리포트를 다시 생성하면 바뀝니다. 이슈 트래커로 옮긴 뒤에는 트래커 번호를 기준으로 써 주세요.
- 재검수 스크립트는 `tools/`에 있습니다 (Playwright, `npm i` 후 사용). 로그인 세션·원시 캡처 데이터(`.auth/`, `raw/`)는 올리지 않았습니다.
