- 제외: `reference/palette-compare.html` (디자인 시스템 비교용 문서, 서비스 화면 아님)

## 0-1. 전제 · 확인 방법

| 항목 | 원본(프로토타입) | 배포본 |
|---|---|---|
| 로그인 상태 전환 | `localStorage.scentrip_auth` — 값이 없으면 **회원(in)**, `"out"`이면 비회원(`html.is-guest`) | Google OAuth 세션 (`/auth/callback`, `/api/session`) |
| 회원 전용 화면 | 대부분 비회원 상태도 같은 파일에서 CSS로 분기 (`.guest-only` / `.auth-only`) | `/dashboard` `/planner` `/mypage` `/signup` 은 비로그인 시 **307 → `/login?next=…`** |
| 검수용 파라미터 | `?tour=1`(튜토리얼 강제) · `?type=코드`·`?state=`(취향 결과) · `?error=`(로그인 오류) · `?reviews=0`(리뷰 빈 상태) · `?embed=1`(약관 모달 안) | 해당 없음 — 실제 데이터/세션으로만 상태 재현 |
| 상세 식별자 | 파일 1개 + 쿼리(`?id=` `?name=` `?saved=`) | 동적 라우트 (`/news/[slug]` `/explore/[id]` `/planner/[id]`) |

> 회원 상태: 배포본은 Google 로그인이 필요하다 → 새 Google 계정으로 가입한 세션을 저장해 검수 (0-6 결정 사항 참고).

## 0-6. 결정 사항 (2026-09-16)

1. 회원 상태 검수 → **(a)** 창을 띄운 브라우저에서 사용자가 **새 Google 계정**으로 직접 로그인·가입하고, 세션은 `qa/.auth/state.json`에 저장 (`qa/.auth/`는 git 제외)
2. 배포본에서 찜 · 동선 저장 · 리뷰 작성/삭제 **실제 실행 허용**
3. 신규 회원 전용 상태(P-02, G-06, P-03d member-first)는 새 계정 가입 때 한 번만 볼 수 있음 → 아래 "한 번만 볼 수 있는 상태" 순서대로 그 자리에서 캡처. **새 Google 계정 2개**: 계정 A = 검사 없이 가입(P-02c → member-first), 계정 B = 비회원 검사 후 가입(P-02d)
4. 취향 결과 16유형: 재현 **가능** (0단계 초안의 "재현 불가"는 오판). 축마다 3문항 중 2개 이상 고른 쪽으로 유형이 정해지므로 답을 골라 16유형을 모두 만들 수 있음. 비회원으로 16회 진행 → 회원 결과 이력이 쌓이지 않게 함

### 배포본에서 일부러 만들 수 없는 상태 (원본 스크린샷만 남기고 [확인필요])
- P-02e 가입 저장 실패, 로그인 오류 중 `failed` · `network` · `expired` · `suspended` · `noemail` — 서버/Google 쪽 실패라 일부러 일으킬 수 없음. 단, 배포본이 `/login?error=코드`를 그대로 받으면 URL로 확인 (1단계에서 먼저 시도). `cancel`은 Google 화면에서 취소해 확인

### 한 번만 볼 수 있는 상태 — 가입 세션에서 캡처할 순서
각 상태에서 4개 뷰포트 full page 스크린샷 + DOM 전체 + 요소별 computed style 을 저장하고 다음 단계로 넘어간다.
1. `/login` → 사용자가 Google 로그인 (새 계정)
2. `/signup` 첫 화면 → 약관 모달 2종 → 닉네임 검증 오류 → 가입 완료하기
3. 가입 완료 화면 (P-02c 또는 P-02d)
4. (P-02c일 때) 첫 검사 → 로딩 → 결과 member-first CTA
5. 첫 방문 튜토리얼: 홈 · 소식 · 탐색 · 내 여행 — 단계마다 캡처
6. 세션 저장 → 이후 회원 화면 검수는 자동으로
7. 맨 마지막: 재검사(member-retest) · 회원탈퇴
