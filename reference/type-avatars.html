16유형 아바타 — 필터용

탐색 · 내 여행 · 동선 만들기의 취향 필터 메뉴에 쓰는 원형 아바타입니다. 온보딩 결과의 전신 캐릭터(assets/character/{코드}.png)를 받침·소품까지 그대로 두고, 빈 여백만 털어 정사각으로 다시 잡았습니다 — assets/character/avatar/{코드}.png · 160×160. 소품이 새보다 커서 작은 원판에서 새가 묻히던 다섯 유형(큐레이터 · 개척자 · 낭만가 · 미학가 · 노마드)만 소품을 빼고 새만 남겼습니다.

실제 크기 (36px)

필터 메뉴에서 보이는 크기 그대로입니다.

크기 사다리

원본이 160px이라 80px까지는 @2x로 선명합니다. 그보다 크게 쓸 자리에는 전신 캐릭터 원본을 쓰세요.

바뀐 점

전: 전신 그림(character/thumb/)을 1.5배 확대해 얼굴 근처를 잘라 쓰던 방식 — 캐릭터마다 얼굴 위치가 달라 받침(책·찻주전자·바구니)이 어정쩡하게 잘리거나 얼굴이 밀려났습니다. 후: 그림은 그대로 두고 프레이밍만 바꿨습니다 — 빈 여백을 털어낸 뒤 원판 가운데에 같은 여백으로 앉혀, 받침까지 그림 전체가 들어옵니다. 다섯 유형만 예외로 소품을 뺐습니다.

필터 메뉴

아바타 36px · 간격 10px · 제목 14px Medium · 설명 11px. 고른 항목은 원판 안쪽 링이 진해집니다(22% → 52%).

만드는 규칙

항목값
원본assets/character/{코드}.png
출력assets/character/avatar/{코드}.png · 160×160 · 투명 PNG
그림받침·소품까지 원본 그대로 — 지우거나 덧그리지 않음.
예외 5종만 소품을 지우고 새만 남김: 큐레이터(찻주전자·김) · 개척자(배낭) · 낭만가(바구니) · 미학가(도자기) · 노마드(등대·바다).
소품이 새보다 커서 36px 원판에서 새가 묻히던 유형들입니다. 지우는 좌표는 tools/make-avatars.py 의 ERASE 에 있습니다
미학가 예외학은 세로로 길어 그림을 다 넣으면 몸통이 작아집니다. 그림을 고치는 대신 맞춤 크기의 1.7배로 키워 담고, 원판 밖으로 나가는 다리 끝·꼬리 깃은 원판이 잘라 냅니다(ZOOM — 배율과 원판 한가운데에 놓을 지점). 다리는 그림에서 지우지 않았습니다
크롭알파 바운딩 박스(알파 14 이하는 여백으로 봄). 얼굴 위치 보정 없음
여백캔버스 한 변의 10% — 160px 기준 사방 16px.
원판이 원형이라 네 귀퉁이가 잘리는데, 이 여백으로 잘리는 양을 알파 기준 1% 아래로 눌렀습니다.
큐레이터 · 사색가 · 개척자 · 낭만가 · 몽상가는 새 한 마리가 통째로 들어와 원판이 꽉 차 보여 여백을 16%로 더 줬습니다(PAD_MORE)
그림자유형 색을 45%로 어둡게 · 투명도 40% · 아래로 4px · 블러 6px
— 백조·갈매기·구름처럼 옅은 캐릭터가 밝은 원판에서 사라지지 않게 하는 용도
원판유형 색 8% → 28% 라디얼 그라디언트(28% 20% 기준) + 안쪽 1px 링 22%

다시 뽑을 때는 tools/make-avatars.py 를 돌리면 됩니다 (python3 -m pip install Pillow 후 python3 tools/make-avatars.py). 원본 캐릭터 그림이 바뀌면 예외 5종의 ERASE 좌표만 다시 잡으면 됩니다.
